Catalogue des applications (SoftInventory)

SoftInventory détient les applications : éditeur, marché qui les couvre, pièces contractuelles, volet RGPD, référents. Sentinelle vient les y lire plutôt que de les ressaisir, et n'y écrit jamais. Laissez vide si vous ne l'utilisez pas : le catalogue reste alors entièrement local.
