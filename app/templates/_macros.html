{# Macros partagées. status_badge(status) Le badge de statut : UNE couleur, UN mot, partout (voir app/libelles.py). Critique / Urgent / À prévoir / OK, et « Non suivi » pour tout le reste. `kind` et `fallback` sont conservés pour les anciens appels : `kind` est ignoré (il n'y a plus de dictionnaire par module), `fallback` remplace « Non suivi » pour une valeur hors palette. #} {% macro status_badge(status, kind=None, fallback=None) -%} {%- set cls = status if status in STATUS_LABELS else 'muted' -%} {{ status_label(status, fallback) }} {%- endmacro %} {# delai_badge(days, status=None, passe='en retard de') Le délai en français, dans la couleur du statut : « dans 12 j », « en retard de 5 j », « aujourd'hui ». `days` : entier, date, ou None (rien).
