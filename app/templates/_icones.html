{# ═══ Icones ═══ Une icone de module se dessine PARTOUT de la meme facon : celle du menu. `icone('bi-key')` rend l'icone Lucide que app/navigation.py associe a ce module (sprite local app/static/vendor/lucide.svg, voir tools/build_lucide_sprite.py) ; une icone sans correspondance reste en Bootstrap (logos de marque), donc rien ne casse. Le SVG herite de `color` comme un , et sa taille de `taille` : un nombre de pixels, ou '1em' pour suivre la taille du texte comme le faisait l'icone Bootstrap qu'il remplace (style.css l'aligne alors sur la ligne de base). Dans un gabarit, les icones d'interface s'importent sous le nom `ico_bi` (« {% from '_icones.html' import icone as ico_bi %} ») : beaucoup de macros ont un parametre nomme `icone`, qui masquerait la macro. #} {# Une icone Lucide par son nom, quand elle ne represente pas un module (nature d'un equipement, par exemple). Doit etre dans le sprite. #} {% macro lucide(nom, taille=16, classes='', style='') -%} {%- endmacro %} {% macro icone(bi, taille=16, classes='', style='') -%} {%- set nom = lucide_de(bi) -%} {%- if nom -%} {{ lucide(nom, taille, classes, style) }} {%- else -%} {%- endif -%} {%- endmacro %}
